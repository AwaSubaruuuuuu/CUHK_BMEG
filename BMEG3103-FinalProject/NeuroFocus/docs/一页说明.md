# NeuroFocus —— 一页说明

**一句话**：用一个通道的脑电（FP1）判断此刻是否在专注，再用一个 3 157 参数的小网络
在普通电脑上实时给出 0–100 的专注概率。

---

## 1. 系统示意图

```
   TGAM 头带（FP1 + 左耳参考）
            │ 蓝牙
   蓝牙接收器 ──USB──► COM7 @57600
            │
            ▼
   ┌──────────────────────────────────────────────────────┐
   │ ① 解析：AA AA len … checksum                          │
   │    1 Hz 大包 → signal / attention / 8 段功率          │
   │    512 Hz 小包 → raw_std / raw_max（伪迹）            │
   │ ② 清洗：前 10 s 丢弃、signal>100 丢弃、稳健 4σ 伪迹    │
   │ ③ 组窗：最近 8 秒 × 14 特征 = 8×14 的小矩阵           │
   │ ④ 推理：Conv1D(16,k3)→Conv1D(20,k3)→Conv1D(24,k3)     │
   │          →GAP→Dense→sigmoid  = 3 157 参数              │
   └──────────────────────────────────────────────────────┘
            │
            ▼
   P(专注) → 实时仪表 / 曲线 / 阈值报警
```

数据流：**512 Hz 字节流 → 1 Hz 特征行 → 8 秒滑动窗口 → 一个概率**。
标签只来自实验协议（静息 = 0，心算 = 1），绝不使用设备的 attention 当标签。

## 2. 模型论证

**为什么是 1-D CNN（3 层）？**

| 方案 | 参数量 | 优点 | 致命问题 |
| --- | --- | --- | --- |
| 阈值法（attention 均值 > 75） | 0 | 零算力 | 每人阈值不同，误报严重（本数据 223/494 静息误报） |
| 全连接（112→64→1） | ≈7 300 | 简单 | 丢时间结构，参数翻倍，易过拟合 |
| **1-D CNN ×3 + GAP** | **3 157** | **保留时间模式、参数最少、可 int8 上 MCU** | 只有 8 个时间步，感受野刚好够 |
| LSTM | ≈5 000+ | 长程依赖 | 有状态、难量化、MCU 上麻烦 |
| Transformer | ≫10 000 | 表达力强 | 小样本必然过拟合，算力不合适 |

三个理由：

1. **时间局部性**：专注表现为"连续几秒的模式"，卷积核在时间轴滑动正好捕捉它；
2. **参数预算**：brief 要求 ≈3k 参数、TFLite Micro 可跑。3 层卷积 + GAP 做到 3 157，
   int8 后 3.2 KB、单次 24.6 kMAC——MCU 上几十微秒；
3. **可解释**：第 3 层 24 个通道各自对应一种"8 秒内的波形模板"，GAP 之后是一个线性层，
   可以打印每个通道的权重，看出模型更依赖哪种模式（见第 4 节）。

**输入为什么是 8×14 而不是原始 512 Hz 波形？**
8 秒的原始波形是 4 096 个点，直接卷积需要的参数与算力远超预算；而且设备已经把
频域信息算成了 8 段功率。14 维特征 = 设备 eSense（attention/meditation/signal）
+ 8 段对数功率 + attention 差分 + 2 个伪迹指标，是"信息量 / 维度"最划算的组合。

**训练与验证**：二元交叉熵 + Adam + 早停（patience 60）+ 时间平移/噪声增强；
**按会话文件分组切分** 80/20（同一段数据不会同时出现在训练和验证），
标准化参数只用训练集计算。反向传播手写，并用中心差分数值梯度校验了全部 3 157 个参数
（余弦相似度 0.99976）——保证"能学"是模型本身的功劳，而不是框架的黑盒。

## 4. 挑战（以及怎么应对）

1. **样本太少**：每位被试 3 段 × 60 s ≈ 170 个窗口，1 人留出后只剩 3 人训练。
   → 增强、GAP 降参、早停、分组切分；报告里明确"每人独立校准"的必要性。
2. **个体差异**：合成数据上验证损失能从 0.45 涨到 17——模型记住了被试特有的漂移。
   → 用本人 2 分钟静息数据重算 μ/σ，再微调阈值；这也是真实部署时的标准做法。
3. **标签噪声**：被试"假装专注"、心算卡住、走神。→ 两种状态都闭眼、都不动手，
   心算段默算"1000 连续减 7"，段末报数写进 `*_tasks.csv` 留行为证据；每段前 10 s 丢弃，多段平均。
4. **伪迹**：眨眼、咬牙、吞咽、头动。→ `signal` 阈值 + `raw_std` 稳健 4σ 规则；
   采集时提醒少动。
5. **设备黑盒**：attention 由厂商算法给出，不可解释。→ 只当特征不当标签，
   报告中单独讨论其影响。
6. **1 Hz 太粗**：8 秒窗口只有 8 个时间步。→ 加 attention 差分；未来可把
   512 Hz 原始波形降采样成多通道输入。
